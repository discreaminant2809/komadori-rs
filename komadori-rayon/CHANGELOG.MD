# Changelog

## 0.2.0

### Added

- `crate::iter::ParFirst`.
- `crate::iter::ParLast`.
- `crate::iter::ParAny`.
- `crate::iter::ParForEachWith::new()`.
- `crate::ops::ParAnd`.
- `crate::ops::ParOr`.
- `crate::tuple::IntoParCollector`.
- `ParallelCollectorBase::funnel()`.
- `UnindexedParallelCollectorBase::try_fold_local()`.
- `UnindexedParallelCollectorBase::trying_options()`.
- `UnindexedParallelCollectorBase::trying_results()`.
- `UnindexedParallelCollectorBase::partition()`.
- `crate::collector::par_partition()`.
- `crate::collector::plumbing::SerialOf`.
- `crate::collector::plumbing::SerialOutputOf`.
- `crate::collector::plumbing::UnindexedSerialOf`.
- `crate::collector::plumbing::UnindexedSerialOutputOf`.
- `Either` type re-export from `either` crate.

### Changed

- Reworked parallel collector traits.
- `Serial` and `Output` from modules generated by `uniquify_serial!`
  additionally add a drop clue for `Self`.
- API surface of `ParallelCollectorBase::map_with()`.
- API surface of `UnindexedParallelCollectorBase::fold_local()`.
- API surface of `UnindexedParallelCollectorBase::nest_local_with()`.
- API surface of `UnindexedParallelCollectorBase::filter_with()`.
- API surface of `UnindexedParallelCollectorBase::filter_map_with()`.
- API surface of `crate::iter::ParForEachWith`.
- API surface of `crate::collector::plumbing::Consumer`.
- API surface of `crate::collector::plumbing::UnindexedConsumer`.
- Renamed `UnindexedParallelCollectorBase::parts_unindexed()`
  to `UnindexedParallelCollectorBase::unindexed_parts()`.
- Renamed `UnindexedParallelCollectorBase::take_parts_unindexed()`
  to `UnindexedParallelCollectorBase::take_unindexed_parts()`.

### Fixed

- `ParallelCollectorBase::tee_mut()` now can accept mutable reference of
  a `?Sized` type.
- `take_parts()` and `take_unindexed_parts()` methods of `nest_local()`, `nest_local_with()`,
  `fold_local()` not actually "taking." (was less efficient, such as unneccessary clones).

### Removed

- `crate::iter::ParForEach::with()`.
- `crate::collector::plumbing::Combiner`.
